## Executive summary

1. **Not ready for mainnet.** Contracts and app are in good shape for a testnet product; governance, audit, infra, and several mainnet pins are not in place.
2. **No external audit.** `docs/audit-package.md:5-9` says nothing has been externally reviewed; the package itself is stale (fee split 20/70/10, Raydium, "nothing deployed", commit `0ea89e5`) and omits StonkzRouter Pyth paths, StockPriceSourceV2, FeeLocker/UniswapV3Migrator, ReferralVault, and the Solana Meteora/pauser/referral code.
3. **Every testnet power sits on one EOA** (`0x1FA9…Bdca`), declared burned in `deployments/46630.json` notes; live `pauser()==0x0` on both EVM launchpads; Solana devnet admin = protocol-withdraw = oracle = migration = upgrade authority (`EJ9q…ADLn`), no pauser PDA. Handover is scripted and tested but never broadcast (`docs/governance-handover.md:3`).
4. **Mainnet pins incomplete:** RH 4663 has no Pyth pin (`RouterWiring.sol:36-44`, `Deploy.s.sol:139-143`) although Pyth is live at `0x8250f4aF…1487a` on 4663 (`getValidTimePeriod()=60`, `chainId()=60101`); Base 8453 has **no config library or deploy script at all**; Arc is all placeholders.
5. **`Deploy.s.sol` mainnet path deploys the old stack** (ChainlinkPriceSource + UniswapV2Migrator, router with Pyth=0/attestationSink=0), not the Pyth + V3 FeeLocker + StockV2 + ReferralVault stack that was tested on testnets; every follow-up must then go through a ≥24h timelock.
6. **CI is red:** every GitHub Actions run since 2026-09-29 failed to start ("recent account payments have failed or your spending limit needs to be increased"); nightly E2E `Run journeys` fails (`gh run view 36813696322`). One run is in progress now.
7. **Launchpad is 191 bytes from the EIP-170 limit** (24,385/24,576, `out/StonkzLaunchpad.sol`, via_ir, `optimizer_runs=100`).
8. **Solana indexer has a real catch-up gap:** after an outage with >20,000 newer program signatures, every pass throws `SolanaRangeTooBusyError` (page cap fixed at 20, not configurable) and the runner dead-letters and skips the range after 5 attempts.
9. **Ops is log-only:** alerts are structured log lines (`metrics.ts:213-219`), no Sentry, no pager/uptime/status page, no Neon backup/PITR mention anywhere, no Railway health checks in the Dockerfiles, no security headers on the Vercel web host.
10. **Legal/compliance is placeholder:** disclosure copy unreviewed (`modals/legal.ts:11-12`), no ToS/privacy pages, no geo/sanctions screening, launch checklist stale (still says 20/10/10/60 and "Solana LP mint supply is 0").
